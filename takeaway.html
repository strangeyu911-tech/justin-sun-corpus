01可以拿走的方法论 10 条

以下方法有一个共同点：它们成立与否，不依赖他的任何预测对错——要么有外部研究背书，要么是数学事实，要么是可独立验证的流程。每条都给了适用边界；对应断言的编号可在卷三核对页溯源。

决策与风险

拿信息代替做决定

买房、择业、选城市这类重大决定，先花固定时间看够样本（他的标准是 100 个起步），把「做决定」这个动作换成「拿信息」。他的原话：有了足够的信息之后就不需要做决定。落到买房上是「前三套只用来建立基准，出现明显更优的再出手」。

边界：「100 个」是他的经验值，不是科学常数；卷二已核对过，流传的「37% 最优停止模型」原片并未出现，是外部整理者套用的术语。但「先探图再下注」的思路本身与决策理论一致。

对应断言：V2-s13-b · V2-s4-c · V2-s4-b　·　出处：卷二「如果只做三件事」/「先探图再下注」

攒数据 → 诊断 → 三策取中 → 持续调

他的 AI 使用流程：① 先积累 2–4 个月的个人数据；② 把现状丢给 AI 做诊断、找方向；③ 同一个问题问 3 个不同的大模型，拿「上中下三策」取中策执行；④ 执行中按反馈持续调整。本质是用模型多样性对冲单一模型的偏差。

边界：「中策」稳健但平庸，不一定最优；重大决定仍需自己的判断兜底。

对应断言：V2-s3-c　·　出处：卷二「零资源起步的三件套」

复利最怕大额亏损

亏 50% 需要翻倍才能回本——这是数学事实，不是观点。所以「留在牌桌上」（控制单次风险敞口）优先于「追求单年高收益」；雪道长度比一年的收益率重要。

边界：金融常识层面的方法论，他本人并无异议；但「什么算大额亏损」他没有给可操作的阈值，这一步只能自己定。

对应断言：V1-057-a · V1-058-a　·　出处：卷一 §06 原始积累三定律
学习与成长

刻意练习四要素

一万小时不是埋头重复：要有老师、要把技能拆分、要逐个纠正、要复盘。这与 Ericsson 的刻意练习研究一致——有反馈的练习才有效，无反馈的重复只是固化动作。

边界：「一万小时」的具体数字在学界争议很大（领域间差异极大）；但「反馈式练习优于无反馈重复」这个内核是稳的。

对应断言：V1-061-a　·　出处：卷一 §06（一万小时不是一个人的事）

演化而非设计（MVP）

产品——以及多数复杂事物——不是一次设计出来的，是先放一个最小可用版本进真实环境、拿反馈、再演化。他举自己的例子：在北大加了二三十个社团，两周过一遍、只留一两家的做法。

边界：适用于试错成本可以拆小的场景；不可逆的大决定不适用这个逻辑。

对应断言：V1-076-a　·　出处：卷一 §10（MVP 与演化）

人生前半场是采样期

他拒绝给「人生意义」的标准答案，只给方法：把人生前 50% 当作采集样本的阶段，先体验、先累积信息，之后才有资格下结论。

边界：采样不等于躺平——他强调的是主动体验和记录，不是被动等待。

对应断言：V2-s9-f　·　出处：卷二 §09 财富自由之后
身体

现在就开始练抗阻

卷二原话称之为全片「唯一既有明确时间窗口、又几乎无争议」的建议：20–40 岁是肌肉投入回报比最高的阶段，抗阻训练越早开始越好。

边界：这条有运动医学共识背书（肌肉量随年龄下降、抗阻训练可显著延缓）；具体训练量因人而异，有伤病史请先咨询专业人士。

对应断言：V2-s13-c　·　出处：卷二附录「如果只做三件事」

无症状也主动建基线

「没病不用查」是多数人的默认；他的做法反过来——开始健身前先让 AI 列出该测的指标（血糖、血脂、好坏胆固醇等），在完全无症状时去医院主动检测，先拿到自己的基线数据。

边界：检测项目与频率应遵医嘱，AI 列的清单只是准备材料，不能替代医生判断。

对应断言：V2-s8-a　·　出处：卷二 §08 认知操作系统

用 AI 记饮食与训练

两个可以直接照做的用法：① 餐前拍一张餐桌照、吃完再拍一张「残局」，交给 AI 算热量与蛋白质，并按「先吃高蛋白」给进食顺序建议；② 训练时拍视频交给 AI，记录组数、次数、重量，按渐进超载原则排下一次的递增计划。

边界：拍照估热量有误差，当趋势参考而非精确计数；训练计划的加重节奏有伤病史请先问专业人士。

对应断言：V2-s2-a · V2-s2-b　·　出处：卷二 §02 用 AI 托管一天
数据主权

本地 Markdown + API 解耦

重要记录落成本地可读的纯文本（Markdown），模型通过 API 调用——数据主权在自己手里，模型随时可换。这是他「AI 个人操作系统」的地基：文件在本地，用 API 读取，换任何模型都不用迁移。

边界：对普通人的可取之处是原则而非实现强度：「别把人生数据锁死在某一家服务里」；是否需要做到他那种全自动程度，看个人需求。

对应断言：V2-s2-c · V2-s13-a　·　出处：卷二 §02 / 附录
